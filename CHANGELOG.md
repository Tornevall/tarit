# Changelog

## 1.0.5 - 2026-07-29

* Add built-in `--help` and `-h` usage information.
* Document directory archiving and archive repacking more clearly.
* Add support documentation for tar-based input formats.
* Fix ZIP extraction option handling.
* Improve mode reporting and handling of directory paths.

## 1.0.4 - 2016-12-25

* Fix archive extraction and directory detection.
* Add explicit version information.

## 1.0.2 - 2016-12-24

* Add support for repacking existing archives into compressed tar archives.

## 1.0.1 - 2016-12-24

* Handle trailing directory slashes.
* Report directory size before archiving.

## 1.0.0 - 2016-12-23

* Initial release with automatic tar creation and selection of the best
  available compressor.
